# Icons: gtk/.config/gtk-*/settings.ini asks for Papirus-Dark. Stock Papirus
# folders are blue, and the black-and-white look needs them white — that recolour
# is NOT a config file (it rewrites /usr/share/icons/Papirus-Dark), so install.sh
# runs `papirus-folders -C white --theme Papirus-Dark` to redo it on a new box.
# papirus-folders itself is AUR: see the note at the bottom.
papirus-icon-theme

# python — only used by local-bin/mono-cursor (stdlib only), which rebuilds the
# Breeze cursor set in monochrome and activates it. install.sh runs it at the end.
python

# Shell + fonts. The desktop uses the stock Noto faces (2026-10-23): Noto Sans
# for GTK/Thunar/rofi, Noto Sans Mono for kitty and the i3bar. noto-fonts ships
# the whole Noto Sans family; FiraCode/Terminus are no longer referenced by any
# config (removed from this list 2026-10-23).
fish
noto-fonts
# uv — Astral's Python resolver, used as a tool runner (e.g. nano-pdf). Not
# needed by the desktop itself.
uv

# Terminal niceties the repo ships configs for
starship
fastfetch

# XDG user dirs (~/Pictures etc.) — screenshot.sh and the GTK bookmarks use them
xdg-user-dirs

# Audio — PipeWire stack. wireplumber is the session manager; pipewire-alsa is
# what lets ALSA-only apps (DaVinci Resolve) have sound at all.
pipewire
pipewire-pulse
pipewire-alsa

# Networking + Bluetooth (the rofi menus talk to nmcli / bluetoothctl)
# iwd is the NetworkManager backend this box uses: see system-files/NetworkManager/
networkmanager
iwd
bluez-utils

# Default handlers for files opened from a file manager — keep in sync with
# gtk/.config/mimeapps.list
sxiv
mpv

# X server + GL. xorg-server comes in with lightdm anyway (and that pulls the
# libinput input driver), but it's listed so a box with nothing graphical
# obviously ends up with a working X. mesa is GL / software rendering —
# essential in a VM, which has no vendor driver to lean on.
xorg-server
mesa

# Headers for the gamepad-idle-guard build (src/gamepad-idle-guard.c, compiled by
# install.sh). On Arch the headers ship inside these lib packages — no -dev split.
# (A compiler is needed too; that's base-devel.)
libx11
libxext
libxss

# Display manager (LightDM + GTK greeter; config in system-files/lightdm/)
lightdm
lightdm-gtk-greeter

# Not in the official repos:
#   waterfox-bin (AUR) - the default browser ($mod+b). Bootstrap an AUR helper
#   with `base-devel git` + paru/yay — the README has a 3-line recipe. On
#   CachyOS repos it's mirrored, so there `sudo pacman -S waterfox-bin` works.
#   papirus-folders-git (AUR) - recolours Papirus folders (the white folders the
#   GTK icon theme depends on). install.sh uses it if present; without it you
#   get blue folders. On CachyOS it's mirrored too.
#   vikunja-desktop-bin (AUR) - the Vikunja desktop client. The Vikunja *server*
#   is not part of this setup: it runs as a rootless podman quadlet on the
#   desktop box (see memory notes 2026-10-25) and is reached over Tailscale at
#   http://vasileioslap.tail009ed7.ts.net:3456 — any machine on the tailnet just
#   needs this client (or a browser) plus `tailscale up` in the same account.
#   Pulls electron43 from extra. Server CORS must stay ON for this client.
#
# In the official repos, but only useful with the Spotify bind ($mod+m).
# spotify-player is the light one (Rust TUI + librespot): ~75 MB vs the official
# client's ~1.8 GB, and it carries the repo's greyscale "oem" theme
# (spotify-player/.config/spotify-player/theme.toml). spotify-launcher runs the
# official CEF client and is kept as a fallback. Each needs its own Spotify dev
# client ID — that lives in the machine-local app.toml, never tracked here.
spotify-player
spotify-launcher
